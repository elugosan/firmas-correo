# Firmas de correo — Trading Plus Icon Alliance

Imágenes públicas que enlazan las firmas de correo de la plataforma (Correo → Mi firma).
Zoho no deja incrustar imágenes al enviar por su API, así que se sirven desde aquí (GitHub Pages).

- `logo-firma.png` — logotipo horizontal (1160 × 310, se muestra a 290 px de ancho).
- `firma-emilio.png` — la firma completa de Emilio en una imagen (2336 × 546, se muestra a 580 px).
- `linkedin.png`, `facebook.png` — iconos de las redes (96 × 96, se muestran a 24 px).

Solo material de marca público: nada de datos de clientes ni de personas.
